# vz
Play videos in the terminal as ASCII characters
<img width="3385" height="2022" alt="image" src="https://github.com/user-attachments/assets/aed506af-c503-402a-9748-0ff04e9418b8" />

## Examples
Render video in ASCII mode: `vz -m 0 [FILE]` \
Render video in GRAY mode: `vs -m 1 [FILE]`
